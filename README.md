# Charle's MTG Collector

## Objective

The objective is to have an app working on laptop and mobile where you can look for MTG cards, record them, know and track there price, records their origin and where they are located, build and track decks...

## Functionalities to add

* Finding cards using different possible input (name, color, role, etc.)
* Record and retrieve cards
* records card's prices
* Add additional informations to cards (e.g. original deck, where they are used, how they were acquired, etc)
* Display cards details, prices over time, decks, etc.
* Track price of collection
* Track sales and money balance
* Card price next to card
* if only one card straight to card details
* having the different functions as "pages" with swap in menu
